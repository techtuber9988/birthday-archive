# The Darshika Archive — Visual Preview

A static visual prototype for the birthday website, built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and preview copy
- `styles.css` — palette, typography, responsive layout and component styling
- `script.js` — subtle scroll reveal interaction

## Run locally
Open `index.html` in a browser. Internet access is needed to load the Google Fonts; fallback fonts are provided.

## Design
- Pop red: `#F52B50`
- Sunshine yellow: `#FFCF40`
- Tangerine: `#FF8B42`
- Warm cream: `#FFF0E7`
- Deep berry: `#7B2638`
- Display: Fraunces
- Body/UI: DM Sans
- Handwritten accents: Caveat

This is a visual prototype, not the complete interactive birthday experience. Replace or refine copy and memories before publishing. Avoid putting private conversations or sensitive details on a public URL.
