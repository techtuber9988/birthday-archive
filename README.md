# The Darshika Archive 🎂✨

An aesthetic, scrapbook-style birthday website and memory archive created with HTML, CSS, and Vanilla JavaScript.

---

## 🚀 Getting Started

### 1. Run Locally
Open `pages/index.html` directly in any modern web browser.

Alternatively, spin up a local development server:
```bash
# Using Python
python -m http.server 8000

# Or using Node.js / npx
npx serve .
```
Then navigate to: `http://localhost:8000/pages/index.html`

> **Note:** An active internet connection is recommended on first load to fetch Google Fonts (`Fraunces`, `DM Sans`, and `Caveat`). Fallback system fonts are provided.

## 🎨 Design System

### Color Palette
- **Warm Cream (Background):** `#FFF0E7`
- **Pop Red (Primary Accent):** `#F52B50`
- **Sunshine Yellow (Highlight):** `#FFCF40`
- **Tangerine (Warmth):** `#FF8B42`
- **Deep Berry (Text & Contrast):** `#7B2638`

### Typography
- **Display Headings:** [Fraunces](https://fonts.google.com/specimen/Fraunces) (Serif, warm editorial feel)
- **Body & UI:** [DM Sans](https://fonts.google.com/specimen/DM+Sans) (Clean, modern geometric sans-serif)
- **Handwritten Accents:** [Caveat](https://fonts.google.com/specimen/Caveat) (Doodle & scrapbook personal touch)

## ✨ Features
- **Birthday Preloader:** Custom animated greeting and countdown screen that transitions into the main experience.
- **Scrapbook Aesthetic:** Polaroid-style cards, paper textures, decorative stickers, and organic layouts.
- **Fluid & Responsive:** Designed to look delightful across desktop, tablet, and mobile displays.
- **Lightweight & Fast:** Pure HTML5, CSS3, and modern Vanilla JavaScript with zero heavy dependencies.
